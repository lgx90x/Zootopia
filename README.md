# Zootopia

Zootopia is a Python project that searches for animals by name, fetches data from the API Ninjas Animals API, and generates HTML output.

## Features

- Search animals by name
- Fetch animal data via API
- Display name, diet, location, and type
- Generate HTML content
- Show a message if no animal is found
- Store the API key in a .env file

## Installation

Install the required packages:
dotenv
requests

Create a `.env` file in the project root with:

API_KEY='YOUR_API_KEY'

## Usage

Run:

python animals_web_generator.py

Then enter an animal name when prompted.

## Dependencies
